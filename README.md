# HOS 2025 居屋單位地圖

以官方「出售居者有其屋計劃單位 2025」重售單位及本年度新推售屋苑銷售情況製作的全港互動地圖。

## 執行

```bash
npm install
npm run dev
```

預設網址為 `http://127.0.0.1:5173/`。

## 資料快照

- 官方最後更新：2026-11-02 20:22
- 仍有單位：13 個屋苑，共 5,306 個單位
- 重售貨尾：8 個屋苑，共 213 個單位
- 本年度新推售：「啟陽苑、匯熙苑、影輝苑、朗風苑、裕豐苑」共 5,093 個單位
- 有超過 40㎡ 未售單位：安樺苑、朗天苑、影輝苑、朗風苑、裕豐苑，共 618 個單位
- 已售罄：啟欣苑、冠山苑、昭明苑、啟悅苑、啟盈苑

單位實用面積由「出售居者有其屋計劃單位 2025」重售及個別新推售屋苑價單配對。官方銷售情況檔案並非實時更新，每日最終銷售情況會在每個選樓日完結後更新。
